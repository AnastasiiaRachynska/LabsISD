This matrix links each requirement to its acceptance criterion, applicable Given--When--Then (BDD) scenario, and planned Jira ticket identifiers. Scenario references use the numbering and titles in Section 5 of \texttt{spec/srs.tex}. Architectural requirements cover the mobile client, REST API resources, and offline synchronization. Test, code, and documentation references remain blank until assigned.

\textbf{Ticket responsibility and authority.} The AI agent handles execution and generation for \texttt{WNT-05}, \texttt{WNT-06}--\texttt{WNT-12}, \texttt{WNT-15} (acceptance test execution with at least 85\% coverage), and \texttt{WNT-16}. For \texttt{WNT-01}, \texttt{WNT-02}, and architectural details in \texttt{WNT-09}--\texttt{WNT-12}, work is collaborative: the agent proposes options and maps requirements; the human reviews and adjusts. Human-only authority applies to \texttt{WNT-03}, \texttt{WNT-04} (Gate 1), \texttt{WNT-13}, \texttt{WNT-14} (Gate 2), and \texttt{WNT-17} (Gate 3). Design validation, implementation verification, and all GO/NO-GO decisions remain exclusively with the human.
